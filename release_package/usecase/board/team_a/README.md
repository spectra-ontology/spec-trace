# Team A — Case Source

**Team A** is a cellular-modem design team responsible for the physical layer and modem
subsystem — the hardware that implements the 3GPP physical layer shipped in mobile
processors. It operates in a separate management line from Teams B and C.

The questions in this folder are real questions raised by the team's engineers during
modem design work, answered by SPECTRA. Each case directory contains the question
(`00_original_question.md`, translated from Korean) and the cited SPECTRA answer
(`01_spectra_answer.md`). To protect individual contributors, no case is attributed to a
named organizational unit.

| Case | Topic |
|---|---|
| `case_001_bfd_two_sets` | SpCell with two BFD-RS sets: BFR random-access trigger and BFD relaxation applicability |
| `case_002_ntn_location_cho` | NTN location-based conditional handover behaviour |
| `case_003_csi_with_cdrx` | CSI reporting interaction with C-DRX |
