# Original-question source-aligned retained-output replay

This separate entrypoint uses the admitted conditional AI-agreement cohort and
released/V1 key by default. The original 133-item compatibility scorer and its
historical V2 default remain unchanged. Both keys here use the whole identical
cohort; changed V2 keys do not remove tasks. An empty cohort has undefined scores.

Use the externally approved manifest SHA, rather than deriving your own trust:

    python3 -B score_source_aligned_retained_portable_v1.py --bundle THIS_DIRECTORY --public-root REPOSITORY_ROOT --expected-manifest-sha256 APPROVED_SHA

The existing published baseline logs and keys remain at their original paths.
Every pinned code/key/log file is checked before prediction scoring. Offline
replay reproduces retained per-run scores, subgroups and paired intervals using
the unchanged canonical-string value-set scorer and fixed pure analysis ASTs.
It does not call a model, database, retriever or network service, or write files.

All560 dispositions remain visible. The package links original author report,
inventory, audit closure and source fixture SHA commitments to separately hashed
public projections. Free audit prose, host paths, raw events and tool arguments
are omitted. The private source fixture and raw audit traces are not republished
or independently revalidated by this replayer. AI agreement is not domain-expert
validation, canonical gold, or certification of original-question correctness.

This is retained original-question value-set scoring, not new named-record
performance or recovery of the original paper's default Core/V2 headline.
Legacy normalization does not grade native typing, named roles, order or
multiplicity. Historical graph/text evidence access and source cutoffs are
unequal or unverified; differences are descriptive. Item bootstrap intervals
do not adjust for template clustering. No publication/deposition status follows
from creating this local package.
