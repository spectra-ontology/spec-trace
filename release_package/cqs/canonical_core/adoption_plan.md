# Adoption requirements

This contract bundle supplements the historical benchmark. Preserve the old
questions, scoring keys and measurements; cite the exact Git snapshot used.
Any revision of a question, population, required role, type, ordering or tie
rule creates a new definition hash and requires current output and review.

Before adopting these definitions as the primary evaluation, the authors should
review all meanings and the distinction between clarifications and substantive
variants. Such author review, independent expert review and practitioner studies
must be documented according to what was actually performed. They are not
completed by the AI cross-review or captured native execution.

For the camera-ready paper, describe required-field scoring separately from
historical answer-column and whole-row scoring. Report the original Core,
31-question diagnostic, separate 36 variants and revised contracts as distinct
populations. No model-performance number for the revised Core is supplied here.
New predictions and reported generation conditions are required for such numbers.

Later archive deposits, DOI assignments and outside download verification are
separate actions. This Git addition does not retroactively change the existing
frozen DOI archives. The detailed author editing plan is maintained privately
with the frozen submission; it is not a claim that the paper has been edited.
