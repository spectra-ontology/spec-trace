# PDCCH recorded-decision contract evidence

This compact package reproduces the ten original graph-relative PDCCH decision
records, their own-source text/status evidence and the exact repaired query's
three-column native/SQL result. The original question, lexical scope, explicit
selector and ten-record extent are preserved. Following standalone contribution
catalogues are removed from the recorded decision bodies.

Run from any directory with Python's standard library:

    python3 -B -I /path/to/evidence/reproduce.py

The default replay recomputes the own-prefix selector from the included immutable
47-row SQLite projection, compares all three saved native columns, checks ten
included source own windows and applied/default styles, explicitly distinguishes
four deleted unknown-range placeholder runs from the preserved inserted concrete
ranges in the updated observation, and runs the unchanged
typed scorer. No database, network, container, private host path or model call is
used. The source-original30 frontier is a pinned validation receipt; default
replay does not reopen those full original reports or certify the whole graph.

The original design provides a finite graph-record lookup and separately stores
table cells. A real table-only104 Agreement/event is not captured in the frozen
Agreement population. Its coarse blind-decoding capability is already present
in selected102, while its later per-FS amendment/event association is not claimed
as recovered. This package does not certify all physical events, a current clean
normative table, current implementation truth or human/expert validation.

The manifest reports zero new admissions and zero model calls. Final local
admission, paid evaluation and public publication are separate integration gates.
