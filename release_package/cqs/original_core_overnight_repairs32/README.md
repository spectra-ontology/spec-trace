The repaired query uses the ontology's Agreement and Meeting relationships to
trace ten PDCCH blind-decoding decisions to their own recorded contents. A
generic boundary rule separates later contribution catalogues; explicit ordering
preserves the original ten-record selection. Both semantic reviews, source XML
locators, saved native output and independent SQL make the trace reproducible.

    python3 -B -I verify_additions.py --bundle .

The command replays the sealed source evidence and unchanged typed scoring
checks. The evidence retains the tracked-placeholder and physical-table frontier
diagnostics with their exact source scopes. The query uses the unchanged frozen
graph; evidence excerpts, gold and reviews are validation inputs only. Model
