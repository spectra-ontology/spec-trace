# Executable decision-to-Spec trace

This package follows the ontology path from Resolution records through referenced CRs to their target Specs. It reconstructs all 3,778 recorded paths and the authored ten-Spec selection, then connects each returned identity to an active same-CR outcome in original report passages and formal register cells.

Run `python3 -B -I -S reproduce.py` in a copied package directory. The standard-library replay checks the fixed seven-unit reviews, original XML and native Word evidence, saved read-only native results against both SQL columns, and 16 unchanged requested-field scoring controls. `scope.json` and the source index bind the source ranges, path-count metric and execution observations.
