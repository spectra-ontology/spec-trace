# Common ten-report source witness

This package concerns a separate source-enriched cohort of three unchanged questions. It does not add to the original 560-question admission count. The frozen content and all old graph facts are retained; one generic source text property is added to 3,176 existing records from ten reports. These witnesses, selected prefixes and semantic reviews are evaluation evidence, not model retrieval inputs.

Run the default source replay from any directory:

```sh
python3 -B -I /path/to/evidence/verify_common3176_portable_source.py
```

It reopens the included raw Word XML/styles, reextracts all 3,176 strings and 52,981 body blocks, checks stable parser identity/bindings, checks all literal RDF additions through the pinned public lexer, and derives the three source prefixes. The raw extraction verifier also checks the 112 unbound marker windows and the DMRS ownership/formatting/boundary witnesses. It does not certify every broad-negative ownership boundary or complete rendered Word/equations.

To reconstruct new files from the pinned original public RDF and relational snapshot, supply the base paths and a new output directory:

```sh
python3 -B -I /path/to/evidence/verify_common3176_portable_source.py --base-ttl /path/to/RAN1-body.ttl --base-sql /path/to/RAN1.sqlite --rebuild-out /new/directory --full-public-facts
```

The recipe checks the base hashes, appends exactly the included generic triples, updates the same property in the four relational representations, checks all old columns/storage types in both directions, and optionally parses the whole enriched graph to compare every label/property/edge with the rebuilt SQL. It requires sufficient host memory and creates no container. The recorded RDF bytes reproduce exactly. SQLite byte identity is checked with recorded SQLite3.37.2; another SQLite engine may require separate semantic verification rather than silently accepting a different hash. The large base/derived RDF, SQL and FTS are deliberately not duplicated here.

The original `content` values, 21,058 Agreement identities and old relationships remain unchanged. Preserving the 17,882 fallback records does not authenticate those records against newly reopened raw sources. Source-window geometry is a retained, reviewable identity/ownership witness. The source and reviews preserve background, adopted TP/LS, strike/redline and technical-topic counterreadings. The original contract supplies no new-change-only requirement. Operational literal search is not a claim of general semantic equivalence.

DMRS uses eight mandatory IDs and any two of three boundary IDs. The full pool retains a duplicate strictly below the reachable boundary; a separately pinned prospective boundary kernel addresses this case without changing the original scorer. Source/native/SQL/semantic/API/public gates remain distinct. All reviews are nonblind AI review; expert validation count is zero. Historical source manifests and reviews are retained byte for byte, so their old paths describe provenance rather than runtime dependencies. Only relative paths in this manifest are resolved by the portable verifier.

The same generic property has known counterexamples outside these three evaluated prefixes: slot, SSB, UCI and PUSCH repetition windows can retain a following contribution. Their compact source-role witnesses are included under `known_scope_limits/`. They have not been removed or changed in this snapshot. Therefore the all-record literal replay must not be described as certification of every ownership boundary, every Agreement body or every topic. The three reviewed question prefixes and full generic data preservation are distinct claims.

The included full-base receipt records an actual rebuild of the same RDF and SQLite hashes, with all89 old tables and all165418 graph nodes/848228 edges checked. A fresh default replay does not rerun that optional mode. To rerun semantic tamper controls (relocation plus4 rejected, internally rehashed corruptions):

```sh
python3 -B -I /path/to/evidence/exercise_portable_common3176_controls.py --out /new/control-output
```
