This package separates original-source evidence, retained-corpus presence probes, actually retrieved candidates, and evidence actually supplied to the model. It contains 23 tasks selected by question type and identifier, after the original experiment and before this support audit. No model scores or gold answers selected the tasks. It is not a preregistered sample of the original experiment.

Run `python3 -B -S verify_saved.py` from this directory. The verifier checks all packaged bytes, re-extracts the located named-field DOCX sources, and recomputes the saved candidate and final-context evidence observations. It makes no model or network calls. Re-running the bounded source-presence probes additionally requires the original frozen corpus SQLite databases and workspace source paths; use `audit.py --help` for that separate diagnostic.

The explicit decision field for RAN3_P1_CQ1-6 is present in an original meeting-report entry and in the final C and D contexts. For the other two named-field tasks, the located source documents do not establish the requested field; this is not a global source-absence claim. For the remaining 20 population, list, structure and chain tasks, identifier presence does not certify that finite contexts contain the complete needed evidence. No exhaustive population sufficiency is certified. The source and graph cutoff/content equivalence remains unestablished.

Raw original archives are preserved with SHA-256 and source-path aliases. They are 3GPP source documents; their original attribution and source terms remain applicable. The package makes no new licensing grant over those documents. No human or expert review, new answer-generation run, new empirical result, or universal RAG-versus-KG information equality is claimed.
