# HARQ Agreement retrieval: source and typed eligibility proof

This local proposal keeps the original English question, ten-result extent, and
numeric meeting selection order. A generic retained-content header boundary
excludes a later contribution title from the own Agreement search predicate.
No source property, graph fact, question-specific Boolean, or model input is added.

Run `python3 -B -I verify_source_proof.py`. The default checks included original
XML/styles, finite record geometry, both exact AI reviews, the saved full-pool
projection, the six legal boundary choices, and typed scoring controls. It does
not execute Neo4j or claim to query the omitted whole frozen database.
For an explicit independent full frozen SQL replay, add `--frozen-sqlite PATH`.
That opt-in file must match the pinned original database SHA; it opens immutable,
read-only and is never used as an automatic host fallback.

The latest ten source reports contribute 3,176 registry windows and 112 unbound
candidate windows. The three older reports add 1,069 registry Agreement windows
and their direct/table candidate checks. These are finite cutoff dependencies,
not an assertion that every window is a correct generic semantic segmentation.
The sixteen possible frozen-prefix records have separately inspected source
ownership and formatting. Fifteen remain: nine mandatory and any one of six
equally recent candidates. Their eligibility is separate from the actual native
limited-ten output. The actual ROOT limited-ten output is included separately, with its unchanged
input, full three-column values, read-only execution metadata, source-before/after
inventory, dual-host guard and owned-stop receipts. The offline verifier binds
those saved bytes to the exact repaired query and independently checks that the
selected ten form one of the six legal ID sets. It never starts a container.
The eight lower-pool alias duplicates are preserved; the
canonical uncapped-pool duplicate rejection is reproduced rather than hidden.

Both reviewers are nonblind AI agents; human expert count is zero. Original
content/equation fields and their saved three-column values remain context.
This proof validates the original scoped literal-record search, not general
technical-topic equivalence, new-change causality, or equation render fidelity.
The known own-final-CR-header synthetic false cut is preserved as a bound on
generalizing the generic predicate beyond this verified finite cutoff.

No API call, new native execution, public change, central admission, or original
560 count increment is performed by this package. Historical receipts remain
unaltered; absolute paths inside them are descriptive origin pins, not live
dependencies. Only explicit optional SQL input may be read outside the package.
