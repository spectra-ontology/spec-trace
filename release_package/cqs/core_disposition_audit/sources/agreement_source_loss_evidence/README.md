# Two bounded Agreement source-span loss diagnostics

These evidence packages preserve ROOT-final `unsupported_frozen_data` findings
for the original PUCCH-resources and SRS-configuration questions. The subtype is
`own_source_span_loss` (Frozen data lacks necessary source facts). They add zero
Core admissions and contain no new model evaluation, technical gold answer,
expert validation, standard-change claim or permanent-impossibility result.

Run from any directory, with Python 3.10+ and only its standard library:

```sh
python3 -B -I /path/to/agreement_source_loss_evidence/reproduce.py
```

The program writes a JSON result to stdout. It reads only this package, rejects
optimized Python, symlinks and extra/missing files, checks exact file hashes and a
code-pinned scientific inventory, then reconstructs the complete latest retained
286 Agreement own windows from the shared original RAN1#123 full document.xml.
It independently recomputes both authored literal predicates and their lexical
identity ranks. AGR-123-9.3-010 is sixth of six PUCCH/resource matches;
AGR-123-7-011 is fourth of eight SRS/configuration matches. Both belong inside
LIMIT10, even without claiming a complete corrected answer for older meetings.

The package contains the original full document.xml/styles.xml compressed once,
the original3176 identity/own-window geometry, two preserved286-frontier receipts,
and a fresh read-only projection of all3176 retained Agreements, their3176
MADE_AT edges, and the full Meeting table. The whole frozen graph has21058
Agreement nodes and21288 Agreement-to-Meeting paths:3176 is the ten-report source
scope, not the whole graph. Fresh whole-database original SQL10 results are
included and exactly replayed from this projection; every excluded Agreement
path is at meetingInt<=116 and both returned prefixes are later, so those older
paths cannot displace any of the reproduced10. The fresh projection recorded
identical original DB SHA before/after with immutable/read-only access.

Direct keyword paragraphs, deletion/strike/hidden flags and referenced/default
style closure are checked from the raw XML. These checks preserve the original
limited formatting evidence; they are not a general Word-rendering or normative
redline certification. Original English/query bytes, original criteria, both
seven-unit reviews, ROOT finals, and authority/counterauthority are unchanged.
Existing absolute paths inside those records are historical provenance only;
the reproducer never follows them or opens any external file.

The existing own source-record association is absent in checked frozen content,
note/equation alternatives and retained incident roles. Historical whole165418-node
decoded-property and alias/relationship audits, including actual older positive
alternatives, are preserved unchanged. The portable default checks their pins and
positive/typed evidence; it does NOT rerun a whole-graph property scan, inspect
external referenced documents or prove that every imaginable inference is
impossible. Nine other report archive/XML pins are preserved as locators, but
only the relevant#123 full XML is included and reparsed here.

The SRS case is deliberately narrow: SRS occurs in enableDefaultBeamPL-ForSRS and
configuration inside ReconfigurationWithSync in a primarily PUSCH/pathloss/handover
TP. This does not establish a newly adopted SRS-configuration proposition or a
semantic topic-classifier gold. In the PUCCH case the keyword context is unchanged
black text; it is not identified with the red modified values. Historical related
PUCCH/SRS information remains positive counterevidence to global-absence claims.
Neither case is converted to an ID-only task. The missing own-record membership
already defeats even that weaker necessary condition.

A future generic source-to-record extraction repair would require a separately
declared input variant, independent fidelity checks and equal input access for
all methods. This diagnostic implements no such repair. Large original SQLite,
TTL and DOCX files are not dependencies of the offline command. The shared source
locator and archive/member/XML hashes are in source/original_archive_and_XML_provenance.json.

The original common3176 geometry hashes Word text (`w:t`) plus OfficeMath text (`m:t`). The two sealed literal-membership audits used Word text (`w:t`) only. This replay independently checks both preserved conventions and does not replace one with the other.
