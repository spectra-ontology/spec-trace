## Replay and interpret a contract

Run from the repository root with Python 3:

```sh
python3 -B -I release_package/cqs/verify_current_release.py
```

The launcher checks the current index, the complete disposition register and saved evaluations 23–43. It needs no credentials or database execution. Individual cohort READMEs provide their standalone replay commands and evidence inventories.

Contract verification combines the original question and preserved design context, two separate nonblind AI semantic reviews, source witnesses, complete captured native records, independent SQL agreement and scorer controls. Review provenance records human/expert review n=0. Each pinned bundle states its exact source population and requested answer roles. Recorded references, CR targets and source decision roles are evaluated according to that item’s contract.

Saved evaluations preserve every first-response outcome, including errors and abstentions, under the declared protocol. Source proof and gold are validation inputs; actual model-visible inputs are recorded in the evaluation package. Cohort scores retain their original denominators. The [source supplement guide](../source_supplements_README.md) identifies separately declared changed-input experiments.
