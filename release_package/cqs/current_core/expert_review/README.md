# Prepared source-first expert review kit

This kit is prepared; no human/expert review has been completed.
Its 560 question-only forms contain the original English without reference
queries, gold answers, repaired schemas or AI judgments. Source documents
must be selected and examined independently of the graph-derived reference.

1. Record reviewer identity, domain qualifications and conflicts.
2. Read the original question and preserved raw records. Record source IDs,
   dates, exact locations, population/relationship scope and any ambiguity.
   Return an independent answer before opening the current contract or gold.
   If the necessary source set is unavailable, record that status explicitly.
3. Save and hash the completed source-first forms. Then open the admitted
   contract/gold via the current index and compare fields, types, population,
   counts, duplicate treatment, ordering and ties.
4. Preserve both answers and every discrepancy. Separate source absence,
   extraction error, query error and scoring error; never overwrite a result
   to make it agree. Pending questions require a resolved interpretation and
   new reference execution before admission.

This package does not certify that all raw-source populations are complete or
available. Raw RAN5 decision/target records are included in the final repair
bundle's source evidence; other source availability must be checked per item.
Public reference material is accessible, so no blind-review guarantee is made.
