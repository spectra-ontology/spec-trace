# Huawei meeting-level documentary contribution trend

This package traces recorded Resolution, Tdoc, submitting Company and Meeting roles to reproduce Huawei's meeting-level contribution percentages. The original query keeps its distinct-Resolution numerator, full meeting trend and numeric meeting order. Meeting name and percentage are the requested answer fields; all five native return columns remain checked.

Run `python3 -B -I -S reproduce.py` from any directory. The standard-library replay uses included loader XML/styles, original register XML fragments, a complete fixed-domain projection, two seven-unit reviews, and saved read-only native/SQL output. It recomputes the 3,773 recorded units, 742 Huawei-positive units and 52 returned meeting rates. No network, model, native container or private filesystem fallback is used. Add `--source-root /explicit/original/repository` only to hash-check the omitted original report archives/loader files and registers against the preserved source pins.

Source-container and wrong-year-literal counterexamples, the original operating definitions, and superseded scope proposals remain included. The default source replay reopens the included loader XML and register fragments. Saved native-original coverage is 3,759 strict full-body locations plus four serialization refinements; ten body nonidentities remain distinguished, and the two remaining Huawei units have bounded original citation panels. The replay does not certify omitted archive bytes, all physical report decisions, causal influence or active Word rendering. `contract/scope_and_supersession.json` records these exact roles.
