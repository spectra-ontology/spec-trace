# Tracing Huawei documentary contributions

The ontology connects recorded Agreements, TDocs, submitting companies and
Meetings to trace Huawei-associated documents. The original English question
and authored fifteen-witness page are preserved. Generic own-content boundaries
retain explicit final CR and following-TDoc attachments.

    python3 -B -I -S verify_additions.py --bundle .

The standalone replay checks three original reports and registers, the complete
latest retained source frontier, all four native columns, two AI semantic reviews
and typed answer controls. The requested answer contains the fifteen TDoc IDs.
Verification uses included evidence and makes no model or database calls.
