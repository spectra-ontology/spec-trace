\noindent\textbf{Scope.} This document contains material trimmed from the
main paper to comply with the ISWC 2026 Resources Track 15-page body
limit. The content is verbatim what would have appeared as Appendices
A--G of the manuscript, and is also reproducible from the released
artifacts (\texttt{ontology/spectra.ttl}, \texttt{shapes/spectra-core.shacl.ttl},
\texttt{cqs/spectra\bk\_cq\bk\_v1.0/cypher/}, and the JSON files under
\texttt{validation/}) shipped at \url{https://github.com/spectra-ontology/spec-trace}
and on Zenodo (DOI: \texttt{10.5281/zenodo.20034872}; minted upon
acceptance). Cross-references prefixed \emph{Appendix} (e.g.,
Appendix~A, Appendix~D) refer to sections within this document; section
references without the \emph{Appendix} prefix point back to the main
paper.
